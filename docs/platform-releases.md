# 平台版本与任务版本

平台代码由管理员通过 GitLab 管理，正式应用使用 systemd；按 systemd-deployment.md 准备不可变版本、维护排空、停服检查与切换。全新基线通过 scripts/init_database.py 建立，后续发布只检查基线，不执行旧库升级。

任务版本独立发布。新任务从 GitLab 审查进入，依赖准备成功后显式发布；自动调度默认关闭。任务代码不允许直接从源码工作目录执行，也不支持 ZIP 上传。

平台回退与任务版本回滚分别操作。回退前核对队列、已运行任务与外部业务结果；不自动重复执行结果不确定的任务。共享输出不放源码目录，不随 Git 删除而清除。
