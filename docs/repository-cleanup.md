# 全新架构清理

本轮按用户确认，平台统一为全新 GaussDB/DWS，无旧数据迁移。

移除：文件数据库适配与建表脚本、MySQL 平台库切换、旧业务 INI 回退、DES 配置解密、旧库增量迁移、旧任务导入和对应专用测试。原平台库备份工具保留为 GaussDB 原生 dump 加共享文件；本地备份/恢复命令只转向同一套 GaussDB 实现。

保留：任务业务库连接、发布与回滚、排队与错峰、授权、DDL 与标签、日志、输出、故障恢复和备份。测试用新建的真实数据库 schema，生产 DWS 验收单独执行。

唯一 SQL 基线 schema/gauss.sql、唯一初始化 scripts/init_database.py、统一后端测试 scripts/test_backend.py。前端构建清空并重建 app/dist，入口不缓存，资源失效时保护未保存内容并提示刷新。

archive 中的日期文档仅保留产品设计与历史讨论，不是部署、升级或验收手册。当前行为以现行文档和测试为准。
