# 旧内容梳理与清理

本次清理针对重复或失效的说明与生成资源，不改任务执行、调度、数据库连接、账号权限或持久化数据。

## 已处理

- 将根目录 OPTIMIZATION 和四份历史检查/建议/暂缓提案归入 [archive](archive/README.md)，补上历史标记和正确链接，避免将阶段性验收状态当成现状。
- 新增[文档导航](README.md)，统一指向当前 systemd、GitLab、依赖、调度与输出说明。
- 更新多层目录、文件输出与任务包示例，删除已失效的“上传 ZIP”和“选择外层目录”操作步骤；改为 GitLab 稳定任务身份、审查差异、准备环境、确认发布。ZIP 下载能力保留。
- 删除旧界面遗留且已无引用的六个字体和五个图片文件；保留仍在配置中使用的默认头像及 favicon。
- 默认头像和兼容 favicon 补入 frontend/public。由 Vite 清空并重建 dist，删除重复的 clean-dist 脚本，避免只清入口文件而残留旧模块和旧资源。定制静态文件应放 public，不能只放 dist。
- 修正 favicon 请求落到前端首页的问题，明确返回图标文件；更新新增 DDL 页签后的旧键盘导航测试断言，保留键盘切换验证。

## 保留依据

- `app/jobs` 是 GitLab 默认任务目录，并非可直接删除的旧运行目录；已有发布版本在持久存储中独立保存。
- GaussDB/DWS、Nacos、DES、通知模块与旧 NewDB 方法仍有配置、运行引用或任务 SDK 兼容用途。未接入某个本地实例不意味着可以从生产依赖中删除。
- 旧历史日志和迁移 SQL/脚本用于历史数据读取与升级；不能因新记录格式不同就删除。
- 已停用接口返回 410，保留明确的停用提示。将这些接口删成 404 无助于清理，反而改变旧客户端行为。
- 本地运行目录、业务输出、账号、连接配置、任务版本与日志均未清理。

当前维护入口见[文档导航](README.md)。历史文档不再承担操作手册职责，后续功能变化应优先更新现行手册。
