# 任务执行流程概览

在任务列表打开“详情 → 执行流程”。首次进入时读取当前配置入口与可安全读取的本地 Python 模块，生成静态流程图；分析不会导入或执行任务，也不会联网。

## 使用

- 默认显示入口流程，查看流程选框可以切换到模块初始化、函数或类方法。
- 节点中标记小圆点表示存在可展开的本地函数。点击节点后，在右侧选择“展开函数流程”，可继续查看调用内部步骤；“返回上层”和“入口流程”用于导航。
- “查看对应代码”切换到代码标签，打开相应文件并定位、高亮源码行。若文件在分析后更新，显示版本变化提示并取消旧行号的高亮，需重新分析后定位。
- 缩放按钮调整显示比例；拖动图中空白区域移动视图；“适应宽度”恢复比例。窄屏会将步骤详情放到图下方。
- “重新分析”读取最新文件；发布、回滚或入口修改后重新打开详情，分析的是当前部署版本。结果显示代码版本或校验，缓存按关联文件内容与版本区分。

## 分析范围

识别 Python 顺序步骤、if 分支、for/while 循环、break/continue、return/raise、try/except/else/finally 和 with。直接本地函数与本地导入别名可以关联展开；普通读取、写入、日志、数据库、消息和外部调用名称会形成初步步骤分类。分类来自方法名称规则，不能替代业务判断。

图是逻辑概览，不是某次运行的执行轨迹。异常虚线表示可能路径；外部库抛出的异常类型与继承关系、动态绑定、对象实例方法、运行时导入、并发执行和外部程序内部流程可能无法确定。复杂表达式中列出的调用用于定位，不能视为严格求值顺序。局部嵌套函数、类定义体、装饰器和默认参数的执行细节暂未展开；未识别结构应结合源码。

仅允许安全读取任务目录内文件，拒绝越界与符号链接，继承当前源代码查看权限；字符串参数不会直接出现在节点标题中。上限为 20 个文件、单文件 128 KiB、总内容 1 MiB、每文件 12000 个 AST 节点、40 个模块/函数、每图 120 个节点及 24 层嵌套；超过上限明确提示或返回可读错误。缓存最多保存 8 份结果。

## 后续模型接入

接口为 `GET /api/taskinfo/flow?pid=<任务编号>`，使用现有登录与角色权限，Web 会转发到调度服务。JSON 使用 `task-flow-1` 结构。

`business_summary`、`description_source` 和节点的可选 `description` 为后续说明增强预留；当前未配置、未调用任何模型。将来模型只补充业务概览和节点说明，节点 ID、源码位置和连线仍由代码分析确定；外部传输必须使用获准的模型服务，模型失败时基础图继续可用。接入模型的配置与实际服务调用尚未实现。

`examples/task-flow` 提供不依赖外部服务的多文件演示，可通过任务包管理发布后查看。浏览器回归服务器可设置 `WFS_BROWSER_FLOW_FIXTURE=1` 加载此例到临时目录，不修改实际任务。
