# 验证范围与内网验收

本包是全新 GaussDB 部署验收包，不包含真实生产数据库账号，也没有连接目标内网 GaussDB。

2026-11-04 补充 Windows + Docker PostgreSQL 18.1 实库验收：32 张平台表已建立；9 项独立 schema 实库测试全部通过，覆盖真实任务执行、事务回滚、服务器超时、行锁、分页、归档、矩阵与并发执行汇总。另验证辅助状态的事务锁、加密业务连接与 NewDB 查询、依赖配置持久化及模拟断库后的 JSON 补写。两个已发布示例均通过真实 HTTP 执行，CSV / JSON / LOG 可预览并下载；浏览器验收 1 项通过，覆盖登录、执行详情、CSV 下载、业务连接与依赖配置重载。重启后配置和执行记录仍在，独立状态目录没有 SQLite 文件。

此次实测修复了 Windows 读取恢复文件时可能阻止后台替换文件的问题：共享读取允许删除，并对短暂占用做有上限的重试。修复后状态/恢复专项 5 项和 root 部署配置 4 项测试通过。本机入口与复现步骤见[Windows PostgreSQL 验证](../../docs/local-postgres-windows.md)。以上使用原生 psycopg，不能替代目标 GaussDB/DWS ODBC、集群与 Linux 服务验收。

本机已执行的针对性验证：25 项测试，22 项通过、3 项按环境跳过。包含状态命名空间、加密配置、事务回滚、请求去重、标签/DDL、队列、执行日志、断库恢复、初始化和固定路径 service 配置。状态适配层使用事务型 DB-API 模拟器，并将生产代码直接打开 SQLite 设为测试失败；模拟器本身不代表 DWS 驱动实机验收。

另运行过 223 项完整后端回归，出现 4 项 Windows 临时数据库/只读目录清理错误、Linux pwd 模块在 Windows 不可用错误，以及一项历史时间标记断言失败。时间标记的跨时区夹具已修复并通过上述复测；其余 Windows/Linux 环境问题未据此声称全部回归通过。前端源码本轮未修改。

首次内网验收应至少完成：

1. 核对 GaussDB 产品、版本、DWS 驱动与系统动态库，执行初始 ddl.sql 和全部迁移（含 008_gauss_state.sql）。确认 32 表检查通过。
2. 确认两个 service 只启动一个 Scheduler，Web 可访问并登录。
3. 保存业务连接、Nexus 和 GitLab 配置，重启两个服务后确认配置、密文和已读状态仍在。
4. 发布并执行一个低风险任务，验证日志、文件输出、调度、请求去重和执行队列。
5. 在隔离测试环境模拟 GaussDB 短时不可用，确认不确定请求不会自动重放、完成结果 JSON 暂存可在恢复后补写。
6. 在目标集群测试命名空间锁、事务隔离、超时、并发与吞吐；长时间断库和高频负载未经本机模拟测试证明。

生产 profile 不创建 SQLite 文件。开发及旧本机测试工具仍可用 SQLite 后端，这些工具不属于本部署启动流程。备份应在加载 runtime.env 的维护环境中执行，GaussDB 原生备份必须包括新增状态表，并与普通文件和密钥配套保存。
